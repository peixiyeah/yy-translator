YY 翻译的首个公开版本。把手机放在两个人中间，双方可以用各自的语言轮流说话、阅读和回复。支持中文、英语、日语、韩语和法语。

- **面对面翻译。** 两侧都能选择语言、按住说话或打开键盘。松手后双方各自看到等待提示，接收方可以自动听译文，也可以点「播放」重听。
- **连续聊天与大字阅读。** 两边的气泡同步更新，点旧消息可放大查看。长译文可滑动阅读，点 × 回到聊天。
- **键盘切换。** 上方键盘朝向对面。下方可在内置键盘和手机输入法之间切换，保留已输入的文字。
- **历史对话。** 本地保存当前与归档对话，可按首句、日期、语言和消息数找回，继续交流。

[查看各项功能的全屏 GIF 和截图](https://github.com/peixiyeah/yy-translator/blob/main/README.md#对话接着聊之前说过的随时看)

**安装**　请在本页 Assets 中下载 `yy-translator-1.0.0.apk`，适用于 Android 8.0 及以上。已有安装的用户请选择「更新」，不要先卸载，以保留本机聊天记录。

**首次使用**　在设置中填写自己的 DeepSeek API Key，测试连接后选择双方使用的语言。法语朗读另需阿里云百炼 Key。识别、翻译和朗读使用云端服务，聊天记录保存在本机。
